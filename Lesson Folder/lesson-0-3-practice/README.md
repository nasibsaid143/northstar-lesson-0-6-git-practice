What is this?

This project is a Python program that analyzes weekly sales data and generates a simple sales report.

Why does it exist?

I created this project to practice Python dictionaries, functions, loops, calculations, and working with data.

How do I run it?

Open the project folder in VS Code and run:

python weekly_sales.py

The program will print the weekly sales report and summary in the terminal.

What's in here?
weekly_sales.py — Contains the weekly sales data and Python functions used to calculate totals, averages, and weekly classifications.
README.md — Explains the project, how to run it, and what the files contain.
