# Regional Sales Summary

A small Python script that summarizes fictional regional sales data.
Built as part of Lesson 0.6 of Coding Temple's AI Data Analytics
Foundations course.

## What it does

The script defines a dictionary of fictional sales values for five
regions, then prints the total and average across all regions.

## How to run

You need Python 3.10 or higher. From the terminal, in this folder:

    python regional_summary.py

(On Mac and Linux you may need `python3` instead of `python`.)
